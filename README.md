# TryHackMe

Repository lưu trữ quá trình học tập, thực hành và các **writeup** của tôi trên [TryHackMe](https://tryhackme.com/).

Mục tiêu của repository là ghi lại quá trình giải các **Rooms, Challenges và Academy modules**, đồng thời lưu lại các kỹ thuật, công cụ và kiến thức đã học trong quá trình thực hành Cybersecurity.

## Cấu trúc Repository

```text
.
├── Academy/
│   └── ...
│
├── Challenges/
│   └── ...
│
└── README.md
```

### Academy

Chứa các nội dung học tập từ **TryHackMe Academy**, bao gồm:

* Module
* Learning path
* Các bài thực hành
* Notes
* Commands
* Kỹ thuật và kiến thức quan trọng

### Challenges

Chứa các **Challenge / Room** đã thực hiện cùng với writeup và các file hỗ trợ nếu có.

Mỗi challenge có thể được tổ chức theo dạng:

```text
Challenges/
└── Challenge-Name/
    ├── writeup.ctb
    └── ...
```

## Nội dung Writeup

Các writeup tập trung vào việc giải thích **quá trình phân tích và cách giải**, thay vì chỉ cung cấp đáp án.

Một writeup có thể bao gồm:

```text
1. Giới thiệu
2. Reconnaissance
3. Enumeration
4. Phân tích dịch vụ
5. Vulnerability Discovery
6. Exploitation
7. Privilege Escalation
9. Flags
10. Tổng kết
```

Tùy thuộc vào loại challenge, nội dung có thể thay đổi.

## Mục tiêu học tập

Repository được sử dụng để theo dõi và hệ thống hóa quá trình học Cybersecurity thông qua thực hành.

Các mục tiêu chính:

* Xây dựng nền tảng về Cybersecurity
* Cải thiện kỹ năng Linux và Windows
* Học phương pháp Pentesting
* Hiểu quy trình Reconnaissance → Enumeration → Exploitation
* Học Privilege Escalation
* Thực hành Web Security
* Phát triển kỹ năng Reverse Engineering
* Viết script để tự động hóa các tác vụ
* Xây dựng tài liệu tham khảo cá nhân
